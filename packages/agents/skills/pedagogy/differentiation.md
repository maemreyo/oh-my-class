# Pedagogy Skill: Differentiated Instruction

Differentiated Instruction (DI) ensures all students can access the curriculum regardless
of readiness, learning profile, or interest. Apply these principles when designing activities.

## The Four Elements to Differentiate

### Content
What students learn.
- Provide tiered texts (same topic, different reading levels)
- Offer vocabulary support for ELL students
- Pre-teach prerequisite concepts for struggling learners

### Process
How students make sense of ideas.
- Offer choice in learning activities (visual, kinesthetic, auditory)
- Vary grouping: individual, pairs, small group, whole class
- Use graphic organizers, manipulatives, or digital tools

### Product
How students demonstrate understanding.
- Offer choice in assessment format (essay, poster, presentation, model)
- Allow extended time for students with learning differences
- Provide sentence frames or rubrics as scaffolds

### Learning Environment
Where and how students work.
- Offer quiet work areas alongside collaborative spaces
- Allow flexible seating where possible
- Establish clear routines for transitions between activities

## Practical Strategies

| Strategy | Description |
|---|---|
| Tiered assignments | Same objective, different complexity |
| Learning menus | Students choose from a set of tasks |
| Think-Pair-Share | Structured peer discussion |
| Exit tickets | Quick formative check at end of lesson |
| Anchor activities | Independent enrichment for early finishers |
